# Contributing · Katkı

**English.** Bug reports and ideas are welcome in [Issues](https://github.com/Talkdedsec/talkdedsec-code/issues) and [Discussions](https://github.com/Talkdedsec/talkdedsec-code/discussions). Changes to upstream VS Code files go through `tlk/rebrand.mjs` or `tlk/ozellestir.mjs`, never by hand, so they survive the next upstream import; run both scripts twice and make sure the second run reports `0 files changed`. Problems that also exist in VS Code itself belong upstream at [microsoft/vscode](https://github.com/microsoft/vscode).

**Türkçe.** Hata bildirimleri ve fikirler [Issues](https://github.com/Talkdedsec/talkdedsec-code/issues) ve [Discussions](https://github.com/Talkdedsec/talkdedsec-code/discussions) altında. Upstream VS Code dosyalarındaki değişiklikler elle değil `tlk/rebrand.mjs` ya da `tlk/ozellestir.mjs` üzerinden yapılır ki bir sonraki upstream içe aktarımında kaybolmasın; iki betiği iki kez çalıştır, ikinci çalıştırma `0 files changed` demeli. VS Code'un kendisinde de olan sorunlar upstream'e, [microsoft/vscode](https://github.com/microsoft/vscode) reposuna aittir.

Security issues: [SECURITY.md](SECURITY.md).
