# Security Policy · Güvenlik Politikası

**English** · [Türkçe](#türkçe)

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through one of these:

- GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting).
- Email: **talkdedsec@proton.me**

Include the version (Help → About), what you found, how to reproduce it and the impact you expect. You will get an answer within 7 days. Please keep the report private until a fix is released.

## Supported versions

Only the latest release receives security fixes. Issues that come from the upstream VS Code core are reported to Microsoft as well and picked up with the next upstream import.

## Türkçe

### Açık bildirme

Güvenlik sorunları için lütfen **herkese açık issue açma**.

Şu yollardan biriyle gizli olarak bildir:

- GitHub: bu repoda **Security → Report a vulnerability** (gizli açık bildirimi).
- E-posta: **talkdedsec@proton.me**

Sürümü (Yardım → Hakkında), ne bulduğunu, nasıl tekrarlandığını ve beklediğin etkiyi yaz. 7 gün içinde yanıt alırsın. Düzeltme yayınlanana kadar bildirimi gizli tut.

### Desteklenen sürümler

Güvenlik düzeltmelerini yalnızca son sürüm alır. Upstream VS Code çekirdeğinden gelen sorunlar Microsoft'a da bildirilir ve bir sonraki upstream içe aktarımıyla gelir.
